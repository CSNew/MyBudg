# MyBudg

Web Application ด้วย C# .NET Core MVC สำหรับจัดการการเงินส่วนบุคคล

## ความสามารถหลัก

- เก็บข้อมูล **รายรับ/รายจ่าย** พร้อมวันที่ รายละเอียด และจำนวนเงิน
- แยกประเภทเป็น **ถังงบประมาณ** (Budget Buckets)
- จัดเก็บข้อมูลการลงทุนแต่ละช่องทาง พร้อมคำนวณ **ต้นทุน / มูลค่าปัจจุบัน / กำไรรวม**
- บันทึกข้อมูลลงไฟล์ JSON ภายใต้โฟลเดอร์ `App_Data` เพื่อคงข้อมูลหลังรีสตาร์ต
- มีปุ่ม **Run Demo** เพื่อโหลดข้อมูลตัวอย่างทันที

## วิธีรัน

```bash
dotnet restore
dotnet run
```

จากนั้นเปิด URL ที่แสดงใน console (เช่น `https://localhost:5001`)


## ทดสอบ

```bash
dotnet test
```
